# AKS Newsletter – July 2026

Welcome to the July 2026 edition of the AKS Newsletter.

This month brings **5 features reaching General Availability** and **5 new Preview announcements**. Here are some of the highlights:

- **Encryption in Transit for Azure Files NFS Shares in Azure Kubernetes Service (AKS)** is now generally available
- **Application Routing with Gateway API** is now generally available
- **Artifact Streaming** is now generally available
- **Node Disruption Policy** enters public preview
- **NAT Gateway V2** enters public preview
- **Automatic zone placement** enters public preview

Let's dive in.

---

## ✅ General Availability Announcements

* **[Generally Available: Encryption in Transit for Azure Files NFS Shares in Azure Kubernetes Service (AKS)](https://azure.microsoft.com/en-us/updates/567787/?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Azure Kubernetes Service (AKS) now generally supports Encryption in Transit (EiT) for Azure Files NFS v4.1 volumes through the Azure File CSI driver.

* **[Generally Available: Application Routing with Gateway API](https://azure.microsoft.com/en-us/updates/567944/?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Managing ingress routing while adopting newer Kubernetes standards can require balancing modernization efforts with existing deployments.

* **[Artifact Streaming – now generally available](https://aka.ms/aks/artifact-streaming?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: [NEEDS DESCRIPTION]

* **[Secure TLS bootstrapping – now generally available](https://aka.ms/aks/secure-tls-bootstrapping?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Is now enabled by default in `westcentralus` and `eastasia`.

* **[Secure Boot – now generally available](https://aka.ms/aks/trusted-launch?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Is now supported when using GPUs with Azure Linux OS.

## 📚 Community Blogs

* **[Stream Model Weights to NVIDIA GPU (vLLM) from Azure Blob Storage using the RunAI Model Streamer](https://blog.aks.azure.com/2026/07/13/runai-streamer-vllm?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: If you serve large language models on AKS, you eventually run into the same wall: every time an inference replica scales up, after a node failure, during a rollout, or when your autoscaler races to meet a traffic spike, the new pod has to load tens of gigabytes of model weights before it can serve a single request. That load time is your cold-start tax, and it lands at the worst possible moment: exactly when you need capacity now. This post shows how to cut it by streaming weights straight from Azure Blob Storage into GPU memory with the RunAI Model Streamer, and walks the full setup end to end on AKS.
