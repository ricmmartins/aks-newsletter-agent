# AKS Newsletter – July 2026

Welcome to the July 2026 edition of the AKS Newsletter.

This month brings **5 features reaching General Availability** and **5 new Preview announcements**. Here are some of the highlights:

- **Encryption in Transit for Azure Files NFS Shares in Azure Kubernetes Service (AKS)** is now generally available
- **Application Routing with Gateway API** is now generally available
- **Artifact Streaming** is now generally available
- **Node Disruption Policy** enters public preview
- **NAT Gateway V2** enters public preview
- **Automatic zone placement** enters public preview

Let's dive in.

---

## ✅ General Availability Announcements

* **[Generally Available: Encryption in Transit for Azure Files NFS Shares in Azure Kubernetes Service (AKS)](https://azure.microsoft.com/en-us/updates/567787/?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: AKS now supports Encryption in Transit for Azure Files NFS v4.1 volumes via the Azure File CSI driver. This enhancement is crucial for ensuring data security during transmission, aligning with compliance requirements for sensitive workloads.

* **[Generally Available: Application Routing with Gateway API](https://azure.microsoft.com/en-us/updates/567944/?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: The Gateway API is now generally available, offering a modern approach to managing ingress routing in Kubernetes. This update is significant for teams looking to adopt newer Kubernetes standards while maintaining compatibility with existing deployment strategies.

* **[Artifact Streaming – now generally available](https://aka.ms/aks/artifact-streaming?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Artifact Streaming is now generally available, providing a streamlined approach to handling large container images and artifacts. This feature reduces build and deployment times, enhancing efficiency for CI/CD pipelines in AKS environments.

* **[Secure TLS bootstrapping – now generally available](https://aka.ms/aks/secure-tls-bootstrapping?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Secure TLS bootstrapping is now enabled by default in `westcentralus` and `eastasia`, simplifying the process of establishing secure communications for Kubernetes clusters. This default setting enhances security posture without additional configuration overhead.

* **[Secure Boot – now generally available](https://aka.ms/aks/trusted-launch?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Secure Boot is now supported for AKS nodes using GPUs with Azure Linux OS, providing an additional layer of security by ensuring only trusted software is executed. This is particularly important for workloads requiring high assurance of integrity and security.

## 🧪 Preview Feature Announcements

* **[Node Disruption Policy (preview)](https://aka.ms/aks/nodedisruptionpolicy?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Introduces a policy framework to manage and minimize disruptions during node maintenance activities. This feature is crucial for maintaining application availability and performance during planned and unplanned disruptions.

* **[NAT Gateway V2 (preview)](https://learn.microsoft.com/azure/aks/nat-gateway#create-an-aks-cluster-with-a-managed-standardv2-nat-gateway-managednatgatewayv2?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Now available in public preview, this version supports `outboundType: managedNATGateway` with `natGatewayProfile.sku: standardV2`, offering enhanced scalability and performance for outbound internet connections in AKS clusters.

* **[Automatic zone placement (preview)](https://aka.ms/aks/automatic-zonal-placement?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Automatically distributes AKS nodes across availability zones to improve resilience and fault tolerance. This feature simplifies cluster setup by eliminating manual zone configuration, ensuring high availability.

* **[Prepared Image Specification (preview)](https://learn.microsoft.com/azure/aks/prepared-image-specification-overview?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Provides a framework for defining and managing custom node images in AKS, streamlining the deployment process and ensuring consistency across environments.

* **[Full caching mode for Ephemeral OS disks (preview)](https://learn.microsoft.com/azure/aks/full-cache-ephemeral-os-disk?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-07)**: Offers full caching capabilities for ephemeral OS disks, significantly enhancing I/O performance and reducing latency for workloads that require fast disk operations.

### Release Highlights

* **[Release 2026-07-17](https://github.com/Azure/AKS/releases/tag/2026-07-17)**: This release includes updates to six components, enhancing stability and performance. Engineers should review these updates to ensure compatibility and leverage improvements in their AKS environments.

### Announcements of upcoming changes and retirements

* On September 14, 2026, [the preview property enableCustomCATrust will retire](https://github.com/Azure/AKS/issues/5826). After this date, the `enableCustomCATrust=true` node pool level field will no longer support enabling Custom Certificate Authority (CA). It's crucial to update clusters and node pools to avoid scaling and certificate update failures by removing the preview property.
* AKS no longer supports creating node pools with Windows Server Annual Channel for Containers. This change affects new deployments, and existing setups should consider transitioning to supported configurations to maintain compliance and support.
