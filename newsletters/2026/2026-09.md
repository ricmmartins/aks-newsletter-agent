## 🧪 Preview Feature Announcements

* **[Public Preview: Flex Nodes for AKS](https://azure.microsoft.com/en-us/updates/571919/?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: Flex Nodes introduce a flexible deployment model allowing hybrid and edge infrastructure to seamlessly integrate as worker nodes with an AKS control plane in Azure. This is crucial for teams looking to leverage diverse environments without compromising on the centralized management offered by AKS.

* **[Public Preview: Ubuntu 26.04 support in AKS](https://azure.microsoft.com/en-us/updates/573214/?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: With Ubuntu 26.04 support, AKS users can align with the latest LTS releases, ensuring enhanced security and compatibility. This update is vital for maintaining a secure and efficient Kubernetes environment as new features and patches are introduced.

* **[Converted to use a managed system node pool (preview)](https://aka.ms/aks/hobo-conversion?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: This preview feature allows AKS clusters to be converted to use managed system node pools in supported regions. It simplifies node management and enhances operational efficiency by leveraging Azure's managed services.

* **[Blue-Green Upgrade (preview)](https://learn.microsoft.com/azure/aks/blue-green-node-pool-upgrade?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: The blue-green upgrade strategy now supports seamless transitions to rolling upgrades, minimizing downtime and risk during deployments. This is essential for maintaining high availability and reliability in production environments.

* **[Cluster Health Monitor (preview)](https://learn.microsoft.com/azure/aks/cluster-health-monitor?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: This preview feature introduces automated node health checks and remediation capabilities, ensuring clusters remain healthy and performant. It's a significant step towards proactive cluster management and reducing manual intervention.

* **[AKS Hyperscale Configuration (preview)](https://aka.ms/aks/hyperscale?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: Now available in public preview, the AKS Hyperscale Configuration allows for scaling AKS clusters to unprecedented levels. This is particularly beneficial for enterprises needing to manage large-scale applications with demanding resource requirements.

## 🔁 Behavioral Changes

* **[LocalDNS](https://aka.ms/aks/localdns?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: Is enabled automatically when the cluster networking configuration supports it.

* **[HTTP proxy](https://aka.ms/aks/http-proxy?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: Or Custom Certificate Authority now reject CA certificate content larger than 35 KB, preventing node bootstrap data from exceeding platform limits.

* **[Managed namespace](https://learn.microsoft.com/azure/aks/managed-namespaces?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: Creation now rejects names beginning with the reserved `kube-` or `aks-istio-` prefixes.

* **[Static Egress Gateway](https://learn.microsoft.com/azure/aks/configure-static-egress-gateway?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: Nodes now deregister from the load balancer before a node-image upgrade reimages them, reducing the risk of interrupted egress traffic.

* **[KMS encryption-at-rest for Kubernetes secrets handled by K8s API with customer managed key](https://learn.microsoft.com/en-us/azure/aks/migrate-key-management-service-platform-managed-key-customer-managed-key?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: On 1.37 cluster with versioned Key Vault key IDs.

* **[Azure Monitor managed service for Prometheus](https://learn.microsoft.com/azure/azure-monitor/containers/prometheus-metrics-scrape-crd#basic-authentication-and-bearer-tokens?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: (ama-metrics) uses namespace-scoped access to Kubernetes secrets for PodMonitor and ServiceMonitor configurations.

* **[Azure Container Linux](https://learn.microsoft.com/en-us/azure/azure-linux/azure-container-linux-overview?utm_source=aksnewsletter&utm_medium=website&utm_campaign=2026-09)**: By that date.
