# AKS Newsletter – May 2026

Welcome to the May 2026 edition of the AKS Newsletter.

This month brings **2 features reaching General Availability** and **5 new Preview announcements**. Here are some of the highlights:

- **application routing add-on** is now generally available
- **AKS GitHub issue** is now generally available
- **Application Gateway for Containers managed add-on + AKS Automatic** enters public preview

- **AKS List Available VM SKUs API** enters public preview

Let's dive in.

## 🔁 Behavioral Changes

* **[AKS Automatic](https://aka.ms/aks/automatic)**: Clusters will be preconfigured with Kubernetes Gateway API via the application routing add-on instead of Managed NGINX ingress with the application routing add-on due to the upstream Ingress NGINX retirement.

* **[Azure Kubernetes Application Network](https://learn.microsoft.com/azure/application-network/overview)**
